# WebCatalog — Мережеве обладнання

Навчальний проєкт із дисципліни «Веб-технології».
Розробляється протягом семестру: від статичної розмітки до застосунку на React.

**Опублікована версія:** https://vadymlytvyniuk.github.io/webcatalog/

---

## Тема каталогу

Каталог містить інформацію про сучасне мережеве обладнання (маршрутизатори, комутатори, точки доступу). Дані взяті з характеристик мережевого обладнання. Каталог буде корисним системним адміністраторам, мережевим інженерам та IT-фахівцям для вибору та порівняння параметрів обладнання.

**Обраний набір даних:** `data/network_equipment.json`

---

## Модель даних

Один запис каталогу:

| Поле | Тип | Опис |
|---|---|---|
| `id` | рядок | унікальний ідентифікатор запису |
| `name` | рядок | назва/модель пристрою |
| `manufacturer` | рядок | виробник обладанння (категорійне) |
| `type` | рядок | тип пристрою (категорійне) |
| `ports` | число | кількість портів (числове) |
| `bandwidth` | число | пропускна здатність (числове) |

## Робочий цикл

Кожна лабораторна робота здається так:

1. внести зміни у файли;
2. на панелі **Source Control** у VS Code написати опис коміту по суті
   (`Додав картку запису`, а не `зміни`);
3. натиснути **Commit**, потім **Sync Changes**;
4. через одну-дві хвилини перевірити опубліковану сторінку;
5. надіслати викладачеві посилання на сайт.
