# WebCatalog — Мережеве обладнання

Навчальний проєкт із дисципліни «Веб-технології».
Розробляється протягом семестру: від статичної розмітки до застосунку на React.

**Опублікована версія:** https://vadymlytvyniuk.github.io/webcatalog/

---

## Тема каталогу

Каталог містить інформацію про сучасне мережеве обладнання (маршрутизатори, комутатори, точки доступу, екрани). Дані взяті з стартового репозиторію, наданого викладачем. Каталог буде корисним системним адміністраторам, мережевим інженерам та IT-фахівцям для вибору обладнання за певними параметрами.

**Обраний набір даних:** `network-devices.json`

---

## Модель даних

Один запис каталогу:

| Поле | Тип | Опис |
|---|---|---|
| `id` | рядок | унікальний ідентифікатор запису |
| `name` | рядок | назва/модель пристрою |
| `vendor` | рядок | виробник обладанння (категорійне) |
| `category` | рядок | категорія пристрою (категорійне) |
| `year` | число | рік виробництва (числове) |
| `ports` | число | кількість портів (числове) |
| `throughput` | число | пропускна здатність (числове) |
| `poe` | булеве | підтримка живлення через Ethernet |
| `price` | число | ціна пристрою (числове) |
| `tags` | масив рядків | набір характеристик пристрою |
| `description` | рядок | текстовий опис пристрою |
| `image` | рядок | зображення пристрою |
| `featured` | булеве | ознака відображення пристрою як рекомендованого |

## Робочий цикл

Кожна лабораторна робота здається так:

1. внести зміни у файли;
2. на панелі **Source Control** у VS Code написати опис коміту по суті
   (`Додав картку запису`, а не `зміни`);
3. натиснути **Commit**, потім **Sync Changes**;
4. через одну-дві хвилини перевірити опубліковану сторінку;
5. надіслати викладачеві посилання на сайт.
